# Ambient for Samsung TVs

An Ambient / Art mode and a clean app launcher for Samsung Tizen TVs, installed as a
[TizenBrew](https://github.com/reisxd/TizenBrew) module.

**What it shows** (choose any mix in settings):

- **Anime scenes**: four animated, procedurally drawn wallpapers (Sakura Dusk, Neon Rain,
  Firefly Shrine, Snowy Village). They work offline.
- **Paintings**: curated public-domain works from The Met (Japanese prints, Impressionism,
  landscapes, old masters), shown Frame-TV style on a mat.
- **Nature photos**: Wikimedia Commons featured pictures (landscapes, mountains, waterfalls,
  Japan, beaches, forests).
- **My wallpapers**: your own 4K video loops or images, from direct links.
- **Trending songs**: the Apple Music top-songs chart for your country.
- **Popular on Netflix**: from TMDB. Needs your own free TMDB API key.
- **Clock, date and weather** overlay (Open-Meteo, no key needed).

**App dock**: press ▼ to open a launcher that shows only the apps you pin. There are no ads and
no Samsung TV Plus.

The app never plays sound, so Spotify or other music can keep playing.

## Remote control

| Button | Action |
|---|---|
| OK | Settings |
| ▼ | Your app dock (OK opens an app; "All apps" lets you pin/unpin with Red or ▶❙❙) |
| ◀ / ▶ | Previous / next wallpaper |
| ▲ | Show / hide clock |
| ▶❙❙ | Pause on the current wallpaper |
| Red / Green / Yellow / Blue | Anime / Paintings / Nature / Mix |
| Back | Close menus |

## Install on the TV

1. Open **TizenBrew → Module Manager → Add module**.
2. Choose the **GitHub** type and enter `YOUR-GITHUB-USERNAME/tv-ambient`. (If it only asks for
   a single name, enter `gh/YOUR-GITHUB-USERNAME/tv-ambient`.)
3. Open **Ambient** from TizenBrew. In TizenBrew's settings you can make it auto-launch.

## Your own wallpapers

Edit `app/my-wallpapers.txt` on github.com, one direct link per line (`.mp4`, `.webm`, `.jpg`,
`.png`, `.webp`). Use only content you have the right to use. Changes reach the TV within a few
hours. For instant updates, set **Settings → Links file** to the file's "Raw" link.

## Updating the artwork list

`art-list.js` is generated by `tools/build_art_list.py` (it collects public-domain works from The
Met Open Access API, sequentially and slowly, to respect its rate limits).
